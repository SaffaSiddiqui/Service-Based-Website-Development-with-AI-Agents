# AGENT.md

## Project Goal
Create a simple service-based website where users can browse available services, view service details, select a service, and submit a request for it.

## Languages / Technologies
- HTML5
- CSS3
- JavaScript

## Target Users
- Visitors looking for a specific service
- New users who want to compare available services
- Users who want to quickly submit a service request

## Main Pages
- **Home** — Intro, featured services, and clear call-to-action
- **Services** — List/grid of all available services with categories or filters
- **Service Details** — Description, benefits, basic information, and request button
- **Request Service** — Form for submitting a request for the selected service
- **Success/Confirmation** — Confirms that the request was submitted
- **About/Contact** — Basic information and contact details

## Core Features
- Browse and search services
- Service categories/filtering
- View individual service details
- Select a service and open its request form
- Request form with name, email/phone, selected service, and message/details
- Basic form validation
- Clear submission confirmation
- Responsive navigation and layout

## Basic User Flow
1. User opens the Home page.
2. User explores featured or available services.
3. User opens a service to view its details.
4. User clicks **Request Service**.
5. The request form is pre-filled with the selected service.
6. User enters the required information and submits the form.
7. Website validates the form and shows a confirmation message.

## Design Requirements
- Simple, modern, and professional service-business style
- Clean layout with clear visual hierarchy
- Easy-to-use navigation
- Consistent typography, spacing, buttons, and cards
- Strong call-to-action buttons such as **Explore Services** and **Request Service**
- Mobile-first and fully responsive
- Accessible color contrast and readable text
- Avoid unnecessary animations, clutter, and overly complex UI

## Instructions for the AI Agent
- Follow this document as the project's source of truth.
- Build the website using **HTML5, CSS3, and JavaScript**.
- Keep the website focused on service discovery and request submission.
- Do not add unnecessary pages or complex features without a clear reason.
- Use reusable components and keep the structure organized if implementation is requested later.
- Keep service information easy to update.
- Preserve the selected service throughout the request flow.
- Validate required form fields and provide clear user feedback.
- Make responsive behavior a requirement, not an optional enhancement.
- Do not invent business claims, reviews, clients, prices, or statistics unless provided.
- Prioritize simplicity, usability, and a clear user journey.

## Final Acceptance Criteria
- Users can easily understand what services are offered.
- Users can browse and open individual service details.
- Users can select a service and reach its request form.
- The selected service is clearly shown in the request form.
- Required form fields are validated before submission.
- Successful submission displays a clear confirmation state.
- Navigation works across all main pages.
- The website is responsive on mobile, tablet, and desktop.
- The design is consistent, readable, and professional.
- The website uses HTML5, CSS3, and JavaScript.
- No unnecessary functionality is included beyond the project goal.
