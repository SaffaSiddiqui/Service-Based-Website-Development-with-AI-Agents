# Service-Based Website

A simple, modern, and responsive service-based website built using **HTML5, CSS3, and JavaScript**.

The website allows users to explore available services, view service details, select a service, and submit a service request.

## Features

* Browse available services
* Search and filter services
* View individual service details
* Select a service
* Submit a service request
* Form validation
* Selected service shown in the request form
* Success/confirmation message after submission
* Responsive design for mobile, tablet, and desktop
* Clean and user-friendly interface

## Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html`.
4. The website will open in your browser.

### Using VS Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click on the file.
4. Select **Open with Live Server**.
5. The website will open in your browser.

## How to Get the Project

1. Open the GitHub repository.
2. Click **Code**.
3. Select **Download ZIP** or clone the repository.
4. Open the downloaded project folder.
5. Open the project in VS Code.
6. Open `index.html` or use **Live Server**.

## User Flow

1. Open the Home page.
2. Explore the available services.
3. Select a service.
4. View the service details.
5. Click **Request Service**.
6. Fill in the request form.
7. Submit the form.
8. View the confirmation message.
